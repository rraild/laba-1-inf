# Информатика. Лабораторная работа № 1

Изучение базовых типов данных языка C. Все четыре задания находятся в `main.c`, код без комментариев. Запросы и результаты выводятся на русском языке в UTF-8.

## Сборка и запуск

Нужен GCC с поддержкой C17. В Linux или на Raspberry:

```sh
make
./informatics_lr1
```

Без Make:

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic -O2 -fsigned-char -fwrapv main.c -o informatics_lr1
./informatics_lr1
```

Вводите числа по одному после запросов: например `65`, `66`, `3.14159`, `-12345.6789012345`. Дробная часть вводится через точку. Целые значения должны помещаться в указанные диапазоны.

## Задания

1. Ввод `char`, `int`, `float`, `double`, эхопечать, форматы вывода, системы счисления и `sizeof`.
2. Границы типов из `limits.h` и `float.h`.
3. Расширение и сужение типов через присваивания; двоичное представление каждого результата с разбивкой по байтам.
4. Арифметика на границах знакового и беззнакового `int`.

`-fsigned-char` выбирает знаковый обычный `char`, в том числе на AArch64. `-fwrapv` задаёт циклическое поведение знакового сложения и вычитания в задании 4. Без этого флага знаковое переполнение имеет неопределённое поведение по ISO C. Сужение к знаковому типу вне его диапазона в C17 зависит от реализации.

Проверено на Raspberry AArch64, GCC 15.2.0, при `-O0`, `-O2` и с санитайзером неопределённого поведения в указанном режиме сборки.
